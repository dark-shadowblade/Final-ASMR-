Extension & Video Settings

One shared settings profile is sent to all five extensions. Prompts remain different and are assigned separately from Create Video.

The app waits for the Flow editor to appear (up to 90 seconds), then attempts each setting in sequence, verifies the prompt insertion, and clicks Generate only if checks pass. Flow's live UI labels may differ; a mismatch stops that account safely and reports an error.
